Lumi Staff iPhone PRO PWA

Upload this whole folder to the same domain/path as the rest of the Lumi system.

Files:
- index.html
- manifest.json
- service-worker.js
- icons/icon-192.png
- icons/icon-512.png

iPhone install:
1. Open Safari on iPhone.
2. Go to the uploaded index.html URL.
3. Tap Share.
4. Tap Add to Home Screen.
5. Name it "Lumi Staff".
6. Open it from the iPhone Home Screen.

QR auto-login:
Use a link like:
index.html?u=kelly&p=1234&k=lumi-turn-manager-v5

Important:
For localStorage sync, this must run on the same domain/origin as Front Desk PRO, Admin Panel, Grid PRO, and Customer Kiosk.
