Lumi Design System

Unified tokens, colors, status chips, buttons, cards, and forms for the Lumi Turn System. Use this as the single visual reference for Front Desk, Lumi Grid, Staff View, Admin, and Kiosk.

Brand Colors

Core Lumi colors. The green is brighter for display visibility while still staying soft through transparent backgrounds.
Lumi Green
rgb(41,153,73)
Used for Available / primary action.
Lumi Gold
#c8a66b
Used for Refreshing / luxury accents.
Lumi Red
#b45b5b
Used for Busy / warnings, toned down.
Lumi Gray
#9b9389
Used for Break / inactive states.

Status System

Internal values stay the same. Only display labels change.
Available
Internal: ready
Highest priority visual. This should pop.
Refreshing
Internal: cooldown
Soft transitional state. No auto-assign.
Busy
Internal: busy
Clear but not too dominant.
Break
Internal: break
Muted, lowest priority.

JavaScript Display Mapping

Do not change internal status values. Only convert for display.
function statusDisplayLabel(status) {
  if (status === "ready") return "Available";
  if (status === "cooldown") return "Refreshing";
  if (status === "busy") return "Busy";
  if (status === "break") return "Break";
  if (status === "off") return "Off";
  return status || "--";
}

function statusDisplayClass(status) {
  if (status === "ready") return "available";
  if (status === "cooldown") return "refreshing";
  if (status === "busy") return "busy";
  if (status === "break") return "break";
  return status || "";
}
