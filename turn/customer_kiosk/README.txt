Lumi Customer Kiosk PWA

Upload this whole folder to the same domain/path.

Files:
- index.html
- manifest.json
- service-worker.js
- icons/icon-192.png
- icons/icon-512.png

iPad install:
1. Open Safari on iPad.
2. Go to the uploaded index.html URL.
3. Tap Share.
4. Tap Add to Home Screen.
5. Name it "Lumi Kiosk".
6. Open it from the iPad Home Screen.

Important:
The kiosk must be on the same domain/origin as the other Lumi turn manager pages if you want localStorage to sync.
